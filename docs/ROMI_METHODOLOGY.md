# Методика расчёта ROMI, выручки и маржи

Реализация: `backend/app/services/romi.py` (формулы) и `backend/app/services/ingest.py`
(атрибуция и агрегация). Соответствует разделу 4 ТЗ.

## Приведение НДС
Расходы Яндекс Директа в Reports API приходят **с НДС** (`IncludeVAT=YES`), а данные
Метрики — **без НДС**. Для сопоставимости всё приводится к единой базе **без НДС**:

```
расход_без_НДС = расход_с_НДС / (1 + 0.20)
```

Функции: `vat_to_net(gross)`, `vat_to_gross(net)` (ставка НДС — константа `VAT_RATE`).

## ROMI
```
ROMI, % = (маржа − расход_без_НДС) / расход_без_НДС × 100
```
- ROMI **не определён** (нет значения), если источник расхода не подключён (`spend = None`)
  или канал бесплатный (`spend = 0` — органика, прямые заходы).
- Пороговая интерпретация в интерфейсе: ≥200% — «масштабировать» (зелёный),
  80–199% — «под наблюдением/проверить» (жёлтый), <80% — «ограничить» (красный).

## Атрибуция сделки к источнику
Сделка привязывается к каналу/кампании по данным Битрикс24 (UTM-метки, источник) и
названию кампании Директа. Правила отнесения кампании к каналу — `CHANNEL_RULES`
в `ingest.py` (по префиксу: «Поиск …» → «Яндекс Директ — Поиск», «РСЯ …» → «— РСЯ»).
Атрибуция звонков — по данным Calltouch (обновление со сдвигом до суток).

## Выручка и маржа
- **Выручка** — сумма оплат, атрибутированных к каналу/кампании (факт оплаты из
  Битрикс24 и/или МойСклад).
- **Маржа** — из отчёта прибыльности МойСклад (`report/profit/byproduct`,
  себестоимость по методу учёта склада). Маржа по брендам — агрегированием прибыльности
  товаров по бренду при его разметке в МойСклад (`margin_by_brand`).

## Границы Этапа 1
- ROMI считается по **первой сделке** (когортный LTV — кандидат в Этап 2).
- Полная методика (частичные оплаты, возвраты, скидки, доставка, разные способы оплаты)
  фиксируется отдельным документом по результатам разведки данных до сдачи работ.
- Применение минус-слов и изменение бюджетов/ставок в рекламном кабинете — **вне Этапа 1**
  (система формирует списки и рекомендации; внесение изменений — на стороне Заказчика).
